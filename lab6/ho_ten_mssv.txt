         + GET    /api/students (Lấy danh sách sinh viên)

         + POST   /api/students (Thêm sinh viên mới, có kiểm tra validate thiếu trường)
         + PUT    /api/students/:id (Cập nhật thông tin sinh viên)
         + DELETE /api/students/:id (Xóa sinh viên)
         + GET    /api/search?q= (Mô phỏng lỗi Reflected XSS)

   [x] BƯỚC 2: Kiểm thử chức năng API với Postman + Newman CLI (Functional Testing)
       - Thiết kế Postman Collection (Student-API-Tests.json) gồm 5 requests:
         1. GET All Students (Verify Status 200, schema response, array length >= 3, response time < 200ms)
         2. GET Student by ID (Verify Status 200, return correct student name "Nguyen Van A")
         3. POST Create Student (Verify Status 201, verify created student name "Pham Thi D")
         4. GET Student Not Found (Verify Status 404, success: false)

   [x] BƯỚC 3: Kiểm thử bảo mật động với OWASP ZAP (DAST - Dynamic Security Testing)

         + Medium: Missing Anti-clickjacking Header (X-Frame-Options)

   [x] BƯỚC 4: Phân tích mã nguồn tĩnh với SonarQube (SAST - Static Application Security Testing)

4. BẢNG SO SÁNH 3 LOẠI KIỂM THỬ TRONG DEVOPS:
------------------------------------------------------------------------------------------------------------------------
| Tiêu chí              | Postman / Newman CLI        | OWASP ZAP (DAST)           | SonarQube (SAST)                  |
|-----------------------|-----------------------------|----------------------------|-----------------------------------|
| Phân loại kiểm thử    | Functional Testing          | Dynamic Security Testing   | Static Application Security Test  |
| Có cần chạy ứng dụng? | CÓ (Chạy trên live API)     | CÓ (Gửi request tấn công)  | KHÔNG (Chỉ phân tích cú pháp code)|
| Phát hiện lỗi gì?     | Sai logic, sai status code, | XSS, SQLi, CSRF, thiếu     | Bugs tiềm ẩn, Code Smells,       |
|                       | sai format dữ liệu trả về   | Security Headers an ninh   | Security Hotspots, bảo trì kém    |
| Cần mã nguồn (Code)?  | KHÔNG (Chỉ cần URL/Endpoint)| KHÔNG (Chỉ cần URL/Endpoint| CÓ (Cần toàn bộ file mã nguồn)    |
| Giai đoạn trong CI/CD | Sau khi Deploy (Post-deploy)| Sau khi Deploy (Staging)   | Rất sớm, TRƯỚC khi Build (Early)  |
| Thời gian chạy        | Rất nhanh (~1 - 2 giây)     | Trung bình (~30 - 60 giây) | Nhanh (~20 - 40 giây)             |
| Khả năng tự động hóa  | Rất cao (Newman CLI)        | Rất cao (ZAP API / CLI)    | Rất cao (SonarScanner / Actions)  |
------------------------------------------------------------------------------------------------------------------------
