# Student Manager

Ứng dụng quản lý sinh viên — DevOps Lab 5

**Version 1.0.0** — Phát triển bởi Nhóm A (Dev A: Nguyễn Văn Nam - DTC235180129)

## 1. Giới thiệu
Ứng dụng Student Manager được phát triển bằng Python, minh họa quản lý mã nguồn chuyên nghiệp bằng Git & GitHub theo mô hình Git Flow.

## 2. Tính năng
- **Quản lý thông tin sinh viên (Student Model)**: Khởi tạo, hiển thị đối tượng sinh viên và chuyển đổi dictionary.
- **Thêm sinh viên mới (add_student)**: Kiểm tra trùng mã sinh viên trước khi thêm.
- **Tìm kiếm sinh viên (search_student)**: Tìm kiếm linh hoạt theo từ khóa không phân biệt hoa thường trong tên hoặc mã sinh viên.

## 3. Cài đặt & Chạy ứng dụng

```bash
git clone https://github.com/namddc/devops-lab5-student-manager.git
cd devops-lab5-student-manager
python src/main.py
```

## 4. Công nghệ sử dụng
- Ngôn ngữ: Python 3.x
- Quản lý mã nguồn: Git & GitHub (Git Flow: `main`, `develop`, `feature/*`)
- Quy trình: Pull Request, Code Review, Merge Conflict Resolution
