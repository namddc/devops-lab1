3. CÁC NỘI DUNG VÀ CHECKPOINT ĐÃ HOÀN THÀNH:
   - [x] Bước 1: Dựng môi trường Managed Nodes (3 Docker Ubuntu SSH containers chạy trong network ansible-lab).
   - [x] Bước 2: Xây dựng Inventory (inventory.ini) phân chia nhóm [webservers], [dbservers], [production:children], thiết lập biến kết nối [all:vars] và cấu hình ansible.cfg. Kiểm tra kết nối thành công: ansible all -m ping trả về "pong" từ 3 hosts.
   - [x] Bước 3: Thực thi Ad-hoc Commands quản lý nhanh hàng loạt server:
         + Kiểm tra OS version (Ubuntu 22.04) đồng loạt trên cả 3 node.
         + Kiểm tra dung lượng ổ đĩa (df -h) và RAM (free -m).
         + Cài đặt package curl đồng loạt trên cả 3 node bằng module apt.
         + Phân phối file hello.txt đến các server web bằng module copy.
   - [x] Bước 4: Viết và thực thi Playbook cấu hình Web Server (playbook-webserver.yml):
         + Tự động cập nhật apt cache.
         + Cài đặt máy chủ web Apache (apache2) và bật dịch vụ tự khởi động (service started & enabled).
         + Triển khai trang web tùy chỉnh index.html.
         + Kiểm tra thành công trang web Apache qua curl và browser: "DevOps Lab 4 — Ansible Managed!".
   - [x] Bước 5: Viết và thực thi Full-Stack Playbook & Minh chứng Idempotency:
         + Cài đặt bộ công cụ phát triển & giám sát (git, htop, vim, sysstat, net-tools).
         + Triển khai file cấu hình /opt/myapp/config.env và script giám sát /opt/myapp/health-check.sh.
         + Chạy script health-check in ra đầy đủ thông số sức khỏe hệ thống.
         + Minh chứng tính Idempotency của Ansible: Chạy lại playbook lần 2 trả về "changed=0, ok=5", chứng minh Ansible không gây side-effect khi cấu hình đã đạt trạng thái mong muốn.
   - [x] Bước 6: Dọn dẹp tài nguyên containers sau khi hoàn thành thực nghiệm.

5. BẢNG SO SÁNH CỐT LÕI (IaC vs CONFIGURATION MANAGEMENT):
   -----------------------------------------------------------------------------
   Đặc điểm              Terraform (Bài 3)              Ansible (Bài 4)
   -----------------------------------------------------------------------------
   Phân loại             Provisioning (IaC)             Configuration Management
   Nhiệm vụ chính        Khởi tạo server, network, S3   Cấu hình, cài đặt phần mềm bên trong
   Trạng thái (State)    Quản lý qua terraform.tfstate  Agentless, kiểm tra thực tế (Idempotent)
   Ngôn ngữ              HCL (HashiCorp Config Lang)    YAML (Human-readable)
   Mô hình kết nối       API Cloud Provider             SSH / WinRM (Không cần agent)
   -----------------------------------------------------------------------------
