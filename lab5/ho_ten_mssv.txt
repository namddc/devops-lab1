5. BẢNG SO SÁNH CỐT LÕI (GIT FLOW vs GITHUB FLOW vs TRUNK-BASED DEVELOPMENT):
   -------------------------------------------------------------------------------------------------------
   Tiêu chí               Git Flow (Áp dụng Lab 5)        GitHub Flow                Trunk-Based Development
   -------------------------------------------------------------------------------------------------------
   Độ phức tạp nhánh      Cao (main, develop, feature,    Thấp (main + feature)      Rất thấp (chỉ main/trunk)
                          release, hotfix)
   Tần suất Release       Theo phiên bản định kỳ          Liên tục (CD)              Nhiều lần trong ngày
   Môi trường phù hợp     Phần mềm đóng gói, Enterprise,  Web Apps, SaaS, Startup    Hệ thống CI/CD tự động cao,
                          ứng dụng di động, học viện      hiện đại                   DevOps trưởng thành
   Xử lý Conflict         Tại develop / release           Tại Pull Request           Rất ít nhờ commit nhỏ và liên tục
   Code Review            Tại PR vào develop              Tại PR vào main            Pair programming hoặc review sau
   -------------------------------------------------------------------------------------------------------
